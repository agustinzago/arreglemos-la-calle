# La app no atiende emergencias

Arreglemos la Calle es para problemas que pueden esperar días, no para situaciones con riesgo para personas. No hay categoría de emergencia ni prioridad urgente: un aviso fijo dice "¿Hay riesgo para personas? Llamá al 911 o al 103". Una calle anegada por la lluvia entra como reporte común; una inundación grande no.
